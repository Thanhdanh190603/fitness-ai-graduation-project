Fitness AI Graduation Project

A graduation project built as a fitness website for beginners. Users can create a profile, check BMI, receive workout schedules, watch weekly training videos, track meals, water and sleep, and submit community blog posts for admin review. The backend can connect to Gemini for AI chat, meal analysis and nutrition suggestions.

React • Vite • Node.js • Express • MongoDB • Gemini API
