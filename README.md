# Fitness AI Web

Do an web huong dan tap luyen the thao bang video, co tinh BMI, tao ke hoach tap luyen bang AI demo, quan cao va goi tra phi.

## Cong nghe

- React + Vite
- Node.js + Express
- MongoDB
- JWT Authentication

## Chay project

1. Cai thu vien:

```bash
npm run install:all
```

2. Tao file `server/.env` theo mau `server/.env.example`.

3. Chay frontend va backend:

```bash
npm run dev
```

4. Them du lieu mau:

```bash
npm run seed --prefix server
```
