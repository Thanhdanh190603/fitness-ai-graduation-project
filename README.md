# Thanh Danh Portfolio

Static portfolio site ready for GitHub and Vercel.

## Deploy on Vercel

1. Create a new GitHub repository, for example `portfolio-thanhdanh`.
2. Upload all files in this folder to that repository.
3. Open Vercel and choose **Add New Project**.
4. Import the GitHub repository.
5. Use these settings:
   - Framework Preset: **Other**
   - Build Command: leave empty
   - Output Directory: leave empty
6. Click **Deploy**.

Vercel will generate a `.vercel.app` link after deployment finishes.
